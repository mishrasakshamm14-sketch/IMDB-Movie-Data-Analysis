# IMDB Movie Data Analysis Using Python

## Project Overview

This project analyzes the IMDB movie dataset using Python and data analysis libraries.

The objective is to explore movie ratings, genres, revenue, popularity, and other movie-related information through data analysis and visualization.

The project is based on an existing IMDB analysis notebook and has been extended with additional movie rankings and genre-based analysis.

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Features

### Original Dataset Analysis
- Exploration of movie data
- Analysis of movie ratings
- Movie revenue comparisons
- Runtime analysis
- Average movie ratings by year
- Data visualization using Python

### Additional Analysis
- Top 10 highest-rated Superhero movies (keyword-based)
- Top 10 best Horror movies
- Top 10 best Science Fiction movies
- Top 10 best Action movies
- Top 10 most-voted movies
- Top 10 best movies released after 2010
- Top 10 highest-rated Comedy movies

## Dataset

The project uses the IMDB Movie Data CSV dataset, containing information such as:

- Movie title
- Release year
- Genre
- Director
- IMDB rating
- Votes
- Runtime
- Revenue

## How to Run the Project

1. Download the Jupyter Notebook (.ipynb) file from this repository.
2. Open Google Colab.
3. Upload the notebook.
4. Download and upload the IMDB-Movie-Data.csv dataset.
5. Ensure the dataset path is correct.
6. Run the notebook cells in order.
7. View the movie rankings, tables, and visualizations.
